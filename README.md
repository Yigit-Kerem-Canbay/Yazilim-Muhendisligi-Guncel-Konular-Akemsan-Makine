## ⚙️ Hedef Sistem: Akemsan AE.HAOD.3C Tomruk Arabası
* **Makine Türü:** Yüksek hızda (0–75 m/dk) hareket eden hidrolik halatlı tambur sistemli tomruk arabası.
* **Fiziksel Riskler:** Ray sonu ezilme riski, hidrolik kancaların sıkıştırma/kesme tehlikesi ve >150 bar hidrolik hat basınç riskleri.
